# Data and input preparation

The notebook uses sklearn.datasets.load_breast_cancer. The underlying UCI Wisconsin Diagnostic dataset is documented and attributed in DATA.md.

Wolberg, W., Mangasarian, O., Street, N., & Street, W. (1995). Breast Cancer Wisconsin (Diagnostic). UCI Machine Learning Repository. https://doi.org/10.24432/C5DW2B. CC BY 4.0: https://creativecommons.org/licenses/by/4.0/. The sklearn loader provides the feature matrix; scaling is fitted on training records.
